# ออกหนังสือรับรอง นักศึกษาวิชาทหาร

เว็บ: https://sarawut2206.github.io/-RD-3/

นักเรียนกรอกข้อมูลของตัวเอง แล้วดาวน์โหลดหนังสือรับรองเป็น PDF (A4) พร้อมพิมพ์
รูปแบบ ระยะห่าง และการเว้นวรรค ทำตามไฟล์ตัวอย่าง (ฟอนต์ TH SarabunPSK 16)

นักเรียนกรอก: เลขประจำตัวประชาชน (เว้นวรรคเป็น `๐ ๐๐๐๐ ๐๐๐๐๐ ๐๐ ๐` ให้เอง), ลำดับในบัญชีรายชื่อ, วัน เดือน ปีเกิด
ตัวเลขทั้งหมดแปลงเป็นเลขไทยอัตโนมัติ ส่วนชื่อ-นามสกุลและเลข นศท. ระบบเติมจากบัญชีรายชื่อเมื่อเปิดใช้ส่วนด้านล่าง
(ถ้ายังไม่เปิด นักเรียนกรอกเองทุกช่อง)

## ครูแก้ค่าคงที่ (วันที่ออกหนังสือ ปีการศึกษา ชื่อผู้ลงนาม เบอร์โทร)

แก้ไฟล์ [`config.js`](config.js) แล้ว commit — เว็บอัปเดตเองภายในไม่กี่นาที
สิ่งที่ควรเปลี่ยนทุกครั้งที่ออกชุดใหม่คือ `issue` (วันที่ให้ไว้) และ `academicYear`

## บัญชีรายชื่อ และเก็บสำเนา Word กับ PDF ลง Google Drive

เมื่อตั้ง `uploadUrl` ใน `config.js` แล้ว เว็บจะทำงานแบบนี้:

1. นักเรียนกรอกเลขประจำตัวประชาชน ระบบถามบัญชีรายชื่อของครู แล้วเติม **ชื่อ นามสกุล และเลข นศท.** ให้ (แก้เองไม่ได้) ถ้าไม่พบในบัญชี จะดาวน์โหลดไม่ได้
2. นักเรียนกรอกลำดับ และวัน เดือน ปีเกิดเอง
3. เมื่อกดดาวน์โหลดหรือพิมพ์ เว็บส่งสำเนาเข้า Drive แยกโฟลเดอร์ตามเลขที่:

```text
นำปลด 2569/
  022 ชื่อ นามสกุล/
    022 ชื่อ นามสกุล.pdf
    022 ชื่อ นามสกุล.docx
```

ชื่อในโฟลเดอร์มาจากบัญชีรายชื่อ ไม่ใช่จากที่เว็บส่งมา ส่งซ้ำจะไม่ทับไฟล์เดิม ไฟล์ใหม่จะมีเวลาที่ส่งต่อท้ายชื่อ

**บัญชีรายชื่อต้องอยู่ใน Google Sheet ส่วนตัวเท่านั้น ห้ามใส่ใน repo นี้** (repo เปิดสาธารณะ และรายชื่อมีเลขประจำตัวประชาชน)

### เตรียมบัญชีรายชื่อ

1. อัปโหลดไฟล์ Excel รายชื่อไปที่ **My Drive** (ไม่ใช่ในโฟลเดอร์ "นำปลด 2569" เพราะโฟลเดอร์นั้นเปิดให้ทุกคนที่มีลิงก์แก้ไขได้)
2. คลิกขวาที่ไฟล์ > เปิดด้วย > Google ชีต แล้วเลือก ไฟล์ > บันทึกเป็น Google ชีต
3. ตรวจว่าแชร์เป็น "จำกัด" (เฉพาะเจ้าของ)
4. คัดลอกรหัสชีต (ข้อความระหว่าง `/d/` กับ `/edit` ในลิงก์)

ระบบหาคอลัมน์จากชื่อหัวตาราง ลำดับคอลัมน์ไม่สำคัญ ต้องมีหัวตารางที่มีคำว่า "นศท", "ประชาชน" และ "ชื่อ"
ชื่อในช่อง "ชื่อ - สกุล" ใช้ได้ทั้งแบบมีคำนำหน้า เช่น `นศท.ชื่อ นามสกุล` หรือไม่มี
เพิ่มรายชื่อชุดใหม่ได้โดยเพิ่มแท็บใหม่ในชีตเดียวกัน

### ติดตั้ง Apps Script (ครั้งเดียว ด้วยบัญชีเจ้าของโฟลเดอร์)

1. เปิด https://script.google.com แล้วกด **โครงการใหม่**
2. ลบโค้ดเดิม วางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
3. แก้สองบรรทัดบนสุด ใส่รหัสโฟลเดอร์ (ข้อความท้ายลิงก์โฟลเดอร์ หลัง `/folders/`) และรหัสชีตรายชื่อ แล้วบันทึก
   อย่า commit รหัสเหล่านี้ลง repo
4. กด **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่** เลือกประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
5. กดอนุญาตสิทธิ์ แล้วคัดลอกลิงก์เว็บแอปที่ลงท้ายด้วย `/exec`
6. เปิดลิงก์นั้นในเบราว์เซอร์ ต้องเห็น `{"ok":true,"service":"nsd-certificate","students":108}` (ตัวเลขคือจำนวนรายชื่อที่อ่านได้ ถ้าเป็น 0 แปลว่าหัวตารางไม่ตรง)
7. ใส่ลิงก์ใน `uploadUrl` ของ `config.js` แล้ว commit

สคริปต์เขียนไฟล์ด้วยบัญชีครู จึงตั้งสิทธิ์โฟลเดอร์ปลายทางเป็น "จำกัด" ได้ และควรตั้งเช่นนั้น เพราะไฟล์มีเลขประจำตัวประชาชนและวันเกิด

หากแก้ `Code.gs` ภายหลัง ต้องทำให้ใช้งานได้เป็น **เวอร์ชันใหม่** ของการทำให้ใช้งานได้เดิม ลิงก์จึงจะไม่เปลี่ยน

### ความเสี่ยงที่ควรรู้

ลิงก์ `/exec` อยู่ใน `config.js` ซึ่งเป็นสาธารณะ ใครรู้ลิงก์ก็ลองถามเลขประจำตัวประชาชนกับบัญชีรายชื่อได้ ถ้าเลขตรง จะได้ชื่อ นามสกุล และเลข นศท. ของคนนั้นกลับไป
คนที่ไม่รู้เลขบัตรของใครเลยจะดึงรายชื่อออกไม่ได้ และอ่านหรือลบไฟล์ใน Drive ผ่านลิงก์นี้ไม่ได้

ถ้า `uploadUrl` เว้นว่าง เว็บจะกลับไปให้นักเรียนกรอกเองทุกช่อง ดาวน์โหลดอย่างเดียว ไม่ส่งข้อมูลออกจากเครื่อง

## รันในเครื่อง

ต้องเปิดผ่านเซิร์ฟเวอร์ (ดับเบิลคลิก `index.html` ตรง ๆ แล้วปุ่มดาวน์โหลดจะไม่ทำงาน):

```bash
python -m http.server 8000
```

แล้วเปิด http://localhost:8000

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `style.css` | หน้าเว็บและตัวหนังสือบน A4 (ตำแหน่งวัดจากไฟล์ตัวอย่าง) |
| `app.js` | ตรวจข้อมูล ถามบัญชีรายชื่อ วาดหนังสือ สร้าง PDF และ Word ส่งสำเนาเข้า Drive |
| `config.js` | ค่าคงที่ของหนังสือ และลิงก์ Apps Script |
| `assets/template.docx` | แบบ Word ที่ไม่มีข้อมูลนักเรียน มีช่อง `{{...}}` ให้เว็บเติม |
| `apps-script/Code.gs` | โค้ดฝั่ง Google สำหรับตรวจรายชื่อและเก็บไฟล์ลง Drive |
| `fonts/` | TH SarabunPSK (ฟอนต์สารบรรณ ของ SIPA แจกจ่ายได้ฟรี) |
| `vendor/` | html-to-image (MIT) แปลงหน้าหนังสือเป็นภาพ และ JSZip (MIT) สร้างไฟล์ Word |

ปุ่ม "ดาวน์โหลด PDF" สร้างไฟล์จากภาพความละเอียดสูง (ตัวหนังสือเลือกคัดลอกไม่ได้)
ถ้าต้องการไฟล์ที่เป็นตัวหนังสือจริง ให้กด "พิมพ์" แล้วเลือก "บันทึกเป็น PDF"
